# Self Aware Room Architecture 
This folder stores architectural and configuration information for the overall SAR architecture.  More specific architectural documents are stored within their respective folders.


## Core Layers

1. Physical room systems (fabrication, projection, audio, sensing).
2. Virtual/compute systems (digital twin, control, tooling).
3. Semantic and AI mediation (abstraction, interpretation, agent support).
4. Operations and documentation (process, standards, lifecycle tracking).

## Initial Integration Focus

- Define message and interface conventions across subsystems.
- Identify minimal viable telemetry and logging requirements.
- Align naming, ownership, and update responsibilities.
