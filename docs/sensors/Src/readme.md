# Sensors Source Code

This directory contains the source code, drivers, and firmware for the various sensors used in the Self-Aware Room project.

## Overview

Here you will find scripts and modules designed to interface with the hardware sensors, handle baseline data reading, and process telemetry before logging.

## Contents

- **Drivers & Interfaces**: Microcontroller and single-board computer integration scripts (e.g., I2C, SPI, UART).
- **Validation Scripts**: Quick test scripts to verify sensor wiring, bus connectivity, and initial data streams.
- **Data Logging**: Baseline collection and streaming logic for local storage and server communication.
